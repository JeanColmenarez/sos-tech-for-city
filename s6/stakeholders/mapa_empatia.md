# Mapatge de stakeholders - El problema de la vivenda / Equip: Daniel, Adam i Jean Piero

## Problema detectat
A l' àrea metropolitana de Barcelona hi ha problemes amb l' accecibilitat a la vivenda a causa de diferents motius ja sigui per els preus o per la quantitat de gent molt superior a la quantitat de vivendes.

## Perfil: Persones que busquen habitatge

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Persones que busquen comprar o llogar un habitatge per poder viure-hi. |
| Com els afecta el problema | Els preus elevats i la manca d'habitatges disponibles dificulten trobar una vivenda assequible. |
| Necessitats | Habitatges a preus accessibles, més oferta i facilitats per accedir-hi. |
| Frustracions / pors | No trobar habitatge, haver de pagar un preu molt elevat o no poder independitzar-se. |
| Expectatives | Que augmenti l'oferta d'habitatges i que els preus siguin més assequibles. |
| Capacitat d'adaptació | Baixa, perquè depenen de les condicions del mercat i dels seus ingressos. |

## Perfil: Gent que viu de lloguer

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Persones que viuen en un habitatge de lloguer i paguen una quota mensual al propietari. |
| Com els afecta el problema | Els lloguers elevats i les pujades de preu dificulten mantenir l'habitatge i estalviar per al futur. |
| Necessitats | Lloguers assequibles, estabilitat contractual i protecció davant les pujades excessives. |
| Frustracions / pors | No poder pagar el lloguer, haver de marxar de casa o no trobar un altre habitatge assequible. |
| Expectatives | Que els preus del lloguer siguin més accessibles i que hi hagi més seguretat residencial. |
| Capacitat d'adaptació | Baixa, perquè canviar de casa comporta despeses i pot ser difícil trobar alternatives. |

## Perfil: Joves i estudiants

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Joves que volen independitzar-se i estudiants que necessiten allotjament durant els estudis. |
| Com els afecta el problema | Els preus elevats i els ingressos limitats dificulten emancipar-se o trobar allotjament a prop dels estudis. |
| Necessitats | Lloguers assequibles, residències d'estudiants i ajudes econòmiques. |
| Frustracions / pors | Haver de continuar vivint amb els pares, compartir pis per necessitat o no poder estudiar a la ciutat desitjada. |
| Expectatives | Poder independitzar-se sense haver de destinar la major part dels ingressos a l'habitatge. |
| Capacitat d'adaptació | Mitjana, perquè poden compartir pis o buscar allotjament en altres zones, tot i que les opcions són limitades. |

## Perfil: Famílies amb dificultats econòmiques

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Són els principals afectats ja que tothom necesita una vivenda per viure i és un dret fonamental per a tots.|
| Com els afecta el problema |Té un impacte en l' economia de la familia, en l' estat de salut. Destinen més del 40-50% dels ingressos a la llar, impossibilitant l'estalvi, limitant la natalitat |
| Necessitats |És necessita que es resolgui el tema dels preus de la vivenda o pujar els sous ja que estan molt descompensats |
| Frustracions / pors | Por a no poder renovar el contracte de lloguer i dificultat d'oferir un projecte de vida estable als fills.|
| Expectatives | Rebre suport econòmic i poder accedir a un habitatge digne i estable. |
| Capacitat d'adaptació | obligats a compartir pis, allunyar-se del centre (hores de transport) o reduir la mida de la llar. |

## Perfil: Propietaris d'habitatges

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Persones que són propietàries d'un o diversos habitatges, destinats a ús propi, lloguer o venda. |
| Com els afecta el problema | Els canvis en els preus i les regulacions del mercat poden afectar el valor dels seus immobles i els ingressos que obtenen del lloguer. |
| Necessitats | Seguretat jurídica, manteniment del valor de l'habitatge i garanties en els contractes de lloguer. |
| Frustracions / pors | Impagaments, despeses de manteniment elevades o canvis normatius que afectin els seus interessos econòmics. |
| Expectatives | Un mercat immobiliari estable que permeti gestionar els habitatges amb seguretat. |
| Capacitat d'adaptació | Alta, especialment si disposen de recursos econòmics i de més d'un immoble. |

## Perfil: Propietaris d'habitatges que hi viuen al pis afectat

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Persones que són propietàries del seu habitatge habitual i hi resideixen. |
| Com els afecta el problema | L'augment del cost de la vida i de les despeses associades a l'habitatge pot dificultar mantenir-lo, especialment si tenen una hipoteca. |
| Necessitats | Poder assumir les despeses de l'habitatge, mantenir-ne l'estat i conservar l'estabilitat residencial. |
| Frustracions / pors | No poder pagar la hipoteca, perdre l'habitatge o haver d'assumir despeses imprevistes elevades. |
| Expectatives | Mantenir el seu habitatge i disposar de mesures que evitin que les despeses siguin inassumibles. |
| Capacitat d'adaptació | Mitjana, perquè poden tenir estabilitat residencial, però vendre o canviar de casa pot resultar costós. |

## Perfil: Inversors

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Persones o empreses que inverteixen en habitatges o projectes immobiliaris amb l'objectiu d'obtenir una rendibilitat econòmica. |
| Com els afecta el problema | L'escassetat d'habitatge i els canvis en els preus o en la regulació poden influir en la rendibilitat de les seves inversions. |
| Necessitats | Un mercat estable, seguretat jurídica i una demanda suficient perquè les inversions siguin rendibles. |
| Frustracions / pors | Pèrdues econòmiques, canvis normatius, augment dels costos i reducció dels beneficis esperats. |
| Expectatives | Obtenir rendibilitat de les inversions i trobar oportunitats en el sector immobiliari. |
| Capacitat d'adaptació | Alta, perquè poden modificar les seves estratègies, diversificar les inversions o invertir en altres sectors. |

## Perfil: Ajuntament

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Administració pública local responsable de gestionar les polítiques d'habitatge, urbanisme i serveis municipals. |
| Com els afecta el problema | Ha de respondre a les dificultats de la ciutadania per accedir a un habitatge i gestionar la demanda d'habitatge assequible. |
| Necessitats | Recursos econòmics, sòl disponible, planificació urbanística i polítiques d'habitatge efectives. |
| Frustracions / pors | No disposar de prou recursos per satisfer la demanda o no aconseguir reduir les dificultats d'accés a l'habitatge. |
| Expectatives | Millorar l'accés a l'habitatge, ampliar l'oferta assequible i reduir les situacions d'exclusió residencial. |
| Capacitat d'adaptació | Alta, perquè pot impulsar plans municipals, ajudes i mesures urbanístiques dins de les seves competències i recursos. |

## Perfil: Associacions de veïns

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Organitzacions que representen els interessos dels veïns d'un barri i defensen la qualitat de vida de la comunitat. |
| Com els afecta el problema | L'augment dels preus pot provocar que els residents hagin de marxar del barri i dificultar que nous veïns hi puguin viure. |
| Necessitats | Habitatge assequible, participació en les decisions municipals i protecció del teixit social del barri. |
| Frustracions / pors | Expulsió dels veïns per l'augment dels preus, gentrificació i pèrdua de la identitat del barri. |
| Expectatives | Que les administracions escoltin les seves demandes i impulsin mesures per facilitar l'accés a l'habitatge. |
| Capacitat d'adaptació | Mitjana, perquè poden organitzar campanyes, presentar propostes i mobilitzar els veïns, però tenen recursos limitats. |

## Perfil: Bancs i entitats financeres

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Entitats que ofereixen hipoteques i altres productes financers relacionats amb la compra d'habitatges. |
| Com els afecta el problema | Els preus elevats dificulten que moltes persones compleixin els requisits per obtenir una hipoteca i accedir a la compra d'un habitatge. |
| Necessitats | Clients amb capacitat de pagament, estabilitat econòmica i garanties per reduir el risc d'impagament. |
| Frustracions / pors | Augment dels impagaments, risc de crèdit i reducció de la demanda de préstecs hipotecaris. |
| Expectatives | Mantenir una activitat hipotecària estable i concedir finançament a clients que puguin assumir els pagaments. |
| Capacitat d'adaptació | Alta, perquè poden ajustar les condicions de finançament, els criteris de concessió i els productes que ofereixen. |

## Perfil: Empreses constructores

| Camp | Descripció |
| --- | --- |
| Descripció del perfil | Empreses dedicades a construir habitatges i desenvolupar projectes immobiliaris. |
| Com els afecta el problema | La manca d'habitatges genera demanda de noves construccions, però els costos elevats, la falta de sòl i els tràmits administratius poden dificultar-ne el desenvolupament. |
| Necessitats | Sòl edificable, finançament, permisos de construcció i materials a preus assumibles. |
| Frustracions / pors | Augment dels costos, retards en les obres, falta de finançament o projectes que no siguin rendibles. |
| Expectatives | Poder desenvolupar nous projectes i contribuir a augmentar l'oferta d'habitatges al mercat. |
| Capacitat d'adaptació | Alta, perquè poden modificar els projectes, els materials i els mètodes de construcció segons les condicions del mercat. |
